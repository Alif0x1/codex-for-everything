# Design rule

- Inspect the existing information architecture and token system before redesigning.
- State `DESIGN_VARIANCE`, `MOTION_INTENSITY`, and `VISUAL_DENSITY` before visual implementation.
- Use one palette, one radius language, and deliberate responsive behavior per surface.
- Prioritize hierarchy, accessibility, real states, and maintainability over decorative novelty.
- Verify the rendered result rather than claiming visual fidelity from source inspection alone.
