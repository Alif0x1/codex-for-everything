# Security reviewer role

Review auth, input, secrets, APIs, uploads, payments, and sensitive data.

- Look for injection, XSS, CSRF, SSRF, insecure direct object access, secret exposure, weak validation, and unsafe logging.
- Verify authorization at the data boundary, not only in the UI.
- Check tenant isolation and provider scopes.
- Treat security checks as evidence-producing work, not a claim of safety.
