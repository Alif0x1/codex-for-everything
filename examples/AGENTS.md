# Example project guidance

Use this file as a starting point for a repository-local Codex contract.

## Product boundary

- State what the product owns and what it delegates to providers.
- Preserve authentication, authorization, tenancy, persistence, and public routes.

## Engineering contract

- Inspect existing conventions before creating a new abstraction.
- Use focused tests for changed behavior.
- Run the repository check command before handoff.
- Report static checks separately from browser, live-provider, migration, and deployment evidence.
