# E2E playbook

Use only when behavior crosses a real browser boundary.

1. Identify route, account, tenant, fixture, and provider prerequisites.
2. Verify unauthenticated, authenticated, loading, empty, error, and success states.
3. Exercise the smallest critical journey.
4. Check mobile viewport and keyboard focus where relevant.
5. Separate UI proof from persistence, email, webhook, migration, and provider proof.
