# Plan playbook

Use for non-trivial feature, bug, refactor, or integration work.

1. Inspect the repository, current diff, package scripts, and relevant runtime paths.
2. State the objective, constraints, affected surfaces, and acceptance checks.
3. Identify the smallest safe file-level plan.
4. Name focused tests and final verification gates.
5. Ask only for decisions that materially change scope or risk.

Codex note: this is a playbook, not a registered slash command.
